# Security

Report a leak or a secret in this repo through GitHub private vulnerability reporting, or leave a private note to the maintainer through the issue tracker. Do not include the secret or the personal data in that note.

## In scope

A secret, a key, a token, a personal name, an email address, a postal address, a hostname, an account id, or a price that was committed here.

## Out of scope

The private blocklist for the leak check. It is not in this repo. A request to change a bot's job belongs in an issue, not a vulnerability report.

## What to expect

The maintainer acknowledges the report, removes the leaked material from the tracked files, and the owner decides what to do about git history.
