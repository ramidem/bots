# Parenting report

User-facing text for Parenting routines. Also follow routine-report.md: verdict first, short, no mail bodies. This file is the household shape.

## Weekday digest

One short chat message to the user. Bullets. Deadlines inside 7 days first, then open to-dos. One source pointer per bullet (a file or a calendar item), never the mail body. On a no-activity day, stay quiet unless a deadline is inside 7 days, then one line. If nothing is due and nothing changed, write the status line and stay quiet.

## Nightly next-day note

A draft email only. Never send it. Cover the next calendar day. Bullets, one source pointer each. If a source tab is signed out, say so and stop.

## Sunday week-ahead

A draft email only. Never send it. Cover the coming week. Deadlines and fees first, one item per bullet, each with a source pointer.

## Friday check-in

One message: what is coming next week, then one commute-friendly, low-cost weekend idea in the user's city. Skip any detail you cannot source.

## Monthly note

One short note: age-fit ideas and one or two small things to try this month. No medical claims. No invented milestones. If a source is missing, say so.

## Status line

Every run, including a quiet one, appends one line as in status-log-line.md. The bracket is `parenting`. `type` is `events` for digests and notes, and `sync` for the saved-file cleanup and the fresh chat.
