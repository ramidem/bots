# Contributing

These are the rules for changes to this repo.

- Write "the user", never a name, email, address, hostname, account id, price, or spreadsheet or document id.
- No keys, tokens, or passwords, and no env var names for them.
- Name tools by kind (calendar, mail, browser, repo host) and not by account.
- Times are in the user's local time zone.
- Dr Egghead is the only writer of `fleet/`. Other bots report changes to it. Outside people open an issue.
- Before any change, run `npm test` and the leak check. Keep the blocklist outside the repo.
- No personal data, keys, hostnames, prices, or ids.

Report a leak as [SECURITY.md](SECURITY.md) describes.
